# Security Policy

## Supported versions

Only the 0.1.x release line is supported.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub's private vulnerability reporting for this repository. Open the **Security** tab of the repository and use private vulnerability reporting there.

- Do not open a public issue, pull request, or discussion for a suspected vulnerability.
- Do not include secrets, such as tokens, keys, or credentials, in your report. Describe the problem and the steps to reproduce it without them.
