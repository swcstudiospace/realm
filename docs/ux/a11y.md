## Non-visual surfaces (CLI specifics)

- `realm` output is piped/mono-safe: labels survive `NO_COLOR`, pipes, and `2>&1` capture. Never gate meaning on ANSI color.
- Machine lines (stdout code/result) and human lines (stderr reason) are separate channels; screen readers consume them in order: code first, reason second.
- Long session ids/paths wrap on word boundaries; nothing truncates into ambiguity (axe not applicable; manual review by A08).
- Linear/GSD: headings in order, `+++ Agent notes` as a labelled disclosure, sub-issue list with links, blocked block uses heading text `BLOCKED — owner decision required`.
