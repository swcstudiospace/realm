# Host plugin gaps

This page is the single place where the unverified behavior, the accepted residuals, the owner decisions and the inferences of Phases 21 to 26 of the host plugin work, the three rows of the Phase 31 boot rehearsals, the three rows of the Phase 43 Kimi rehearsal and the four rows of the Phase 48 production tiers and Grok attribution, are tracked. Each row comes from a line of a phase's verification record or context (the Source column names it), has a class and a status, says what evidence exists now and says what would change the row. The test `test/docs/host-gaps.test.ts` checks the shape of the table, that every source exists, that every Phase 21 to 25 unverified item has a row, and that a row marked closed or narrowed points at a file in the repository. The boot status of the five wave 1 hosts and the three Phase 48 hosts, one row each, is on [Wave 1 boot matrix](wave1-boot-matrix.md).

A row changes status only when an automated check or a dated run supports the change, and the evidence goes in the same edit. A gap is never closed by wording alone. Nothing on this page registers Realm in a live host configuration: that needs the owner's explicit approval per host, as [Host plugin contract and installer](host-plugin-contract.md) states. The per-host picture is on [Host support matrix](host-support-matrix.md); to add a host and its gaps, read [Writing a Realm host plugin](writing-a-host-plugin.md).

## Legend

| Class | Meaning |
| --- | --- |
| `unverified-behavior` | something that was not observed and must not be claimed |
| `accepted-residual` | a known limit that is documented and not fixed |
| `owner-decision` | a scope decision taken by the owner |
| `inference` | a fact taken from documentation or another tool and not confirmed on the host |

| Status | Meaning |
| --- | --- |
| `open` | nothing supports a change yet |
| `narrowed` | part of the gap has evidence and the rest remains; the row says which |
| `closed` | evidence supports closing it; the row cites it |
| `accepted` | the gap stays and the owner or the contract page accepts it; the row says what would lift it |
