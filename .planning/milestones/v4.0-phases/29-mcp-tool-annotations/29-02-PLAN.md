## Trust Boundaries

| Boundary | Risk |

## STRIDE Threat Register

| ID | Category | Threat | Severity | Disposition | Mitigation |
| --- | --- | --- | --- | --- | --- |
| T-29-09 | Tampering | The built `realm mcp` lists annotations that differ from the pins (a stale build, a bundling step) | medium | mitigate | `check:mcp` compares the built server's `tools/list` in both eras with an independent literal table; 90 seeded faults prove each check bites |
| T-29-10 | Repudiation | The three copies (pins, gate, docs) drift and one of them is silently wrong | medium | mitigate | One test requires smoke table equals pins; one requires docs table equals pins; mutating any single copy fails a named test |

| T-29-12 | Information disclosure | The docs leak a host-local path or a secret | low | mitigate | `check:docs` host-path scan plus the Q9 test for path prefixes; the section contains only repository paths and public URLs |
