| --- | --- |
| Window to the shared production stack | A live run overlaps another, leaves residue, or is retried silently after a failure |
| Window to the operator's real host configuration | A host registers Realm in a real file |
| Evidence to the repository | A path, an environment value or a secret is committed; a result is overstated |
