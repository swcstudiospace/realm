<objective>
Remove the `degraded` lifecycle state and the `display.degraded` status field, and reduce every consumer to the states that remain.

Purpose: ANDAX-03 (the degraded state is removed with no shim) and the state machine, status labels and schemas part of ANDAX-04. Plan 28-01 left `degraded` valid but unreachable; this plan removes it.
Output: two commits (the state, then the field) plus a gate-data commit only if the allowlists change, each compile-green, with the test and fixture edits they force. Each commit uses the subject fixed for it in 28-CONTEXT D-28-09; the subject is the only text the generated release notes show.
Non-goals: no documents (28-03); no new state, label or code; no migration of stored records (D-28-07); no change to `STATUS_LABELS`, the Omp label format, the mutation-gate decision for the other states, or the MCP tool schema.
</objective>
