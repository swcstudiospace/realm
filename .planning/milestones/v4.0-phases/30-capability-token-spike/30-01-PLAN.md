## Trust Boundaries

| Boundary | Risk |
| --- | --- |
| Prototype to the file system | The script writes outside its scratch directory, into the repository, or into the real home |
| Prototype to the process table | A spawned reader or holder outlives the run; a child reads another user's data |
| Prototype output to the repository | A token, key or host path lands in the SUMMARY or the note |
| Scratch npm install to the machine | A fetched package runs code at install time or leaves files in the repository |
| Note to the reader | The prototype is read as a secure design, or the criteria are bent after the results |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
