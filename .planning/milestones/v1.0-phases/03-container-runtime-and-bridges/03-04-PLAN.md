<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller -> LibpodClient | Method arguments cross into socket requests; only id, label key/value, and timeout cross, never paths or method names |
| libpod socket -> client | Socket bytes cross into the controller path; malformed JSON fails with a typed error, never a raw throw |
| socket file -> container | The API socket grants full Podman access as the user (podman.md Q4); it must never be mounted into a session container |
