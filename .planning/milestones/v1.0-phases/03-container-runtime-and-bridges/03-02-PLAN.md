<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| podman --version stdout -> parser | Untrusted version text crosses into gating; unparseable output must fail to UNSUPPORTED, never pass |
| caller config -> RuntimeConfig | Image references and URLs cross into load; tag-only and userinfo forms must be rejected before any use |
| socket path -> connector | Filesystem path crosses into the socket dial; only the XDG-derived podman.sock path is ever dialed |
