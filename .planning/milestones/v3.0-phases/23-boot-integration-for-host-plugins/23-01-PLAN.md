<objective>
Build the host-neutral half of the boot contract: one attach sequence, one production boot driver that implements the Phase 21 `HostBootHook` port for every `mcp-config` host, the manifest and adapter changes that make it the production `bootHook`, and the read side of per-host presence.

## Trust Boundaries

| Boundary | Risk |
| --- | --- |
| Host process → driver (`call`, `guard`) | A hostile or buggy host feeds malformed tool maps, non-string names or floods calls during a bad boot |
| Driver → daemon client | A stale or foreign client adopted after a swapped workspace, another session's reply or a late attach |
| Daemon status reply → readback | A reply naming another root or session, or no root, adopted as ours |
| Presence directory → doctor and status | Forged, oversized, symlinked or flooded markers change what an operator reads |
| Manifest and launch args → process start | A launch built from untrusted text |
