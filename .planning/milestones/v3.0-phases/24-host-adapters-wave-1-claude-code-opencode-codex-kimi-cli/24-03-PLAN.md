Output: one helper module, one hermetic helper test, four gated live files, a recorded run.
Non-goals: no `src` change; no change to the production-stack harness; no model prompt is ever sent (no credentials are used or forwarded); no live registration in any real host configuration; Kimi Code (`kimi-code`) has no documented validator command and gets no live file (its gap is written in 24-04).
