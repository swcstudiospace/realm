## Trust Boundaries

| Boundary | Risk |
| --- | --- |
| Boot matrix to the developer's real state directory, daemon and sockets | A matrix connects to or stops a real daemon, or writes to a real state directory |
| One host's boot to a sibling host, the sandbox and the daemon | A hung or failing boot takes a sibling down, or a boot path sends `down` |
| Hostile text (project directory name, host value) to the log, report, metric, audit and marker sinks | Control characters or a token reach a sink |
| Seeded defects to production code | A faulty hook or decorator is imported by src |
| Matrix results to the docs | A fakes-only result is read as live evidence |
