# Phase 11, plan 01: milestone v2.0 close, up to the owner's confirmation

Status: written 2026-10-28 by the orchestrator. It runs the sanctioned reorganisation, the dry run and the cleanup. It stops before `milestone complete --confirm`, which is the owner's decision (the archive is irreversible), and before any push, PR, merge or release.

## Goal
Everything the milestone close needs is done and measured, so that the owner's single decision is whether to confirm. The two success criteria of the phase: the gsd-tools dry run completes before the milestone is completed, and the scratch profiles and worktrees created for the milestone are removed.

## Tasks
1. **Sanctioned reorganisation (decision D-006, owner-approved 2026-10-24).** Collapse the v1 phases 1 to 7 of ROADMAP.md under one `<details>` block with a one-line summary per phase, keep phases 8 to 11 and the 9.x phases as the milestone's phases, keep the progress table, and keep the Backlog section if there is one. Use the write guard's single-use sentinel as `workflows/complete-milestone.md` describes, because the rewrite shrinks the file. Check afterwards that no phase detail, success criterion or requirement ID was lost (diff the set of phase headings and requirement IDs before and after).
2. **Roadmap analysis.** `gsd-tools query roadmap.analyze` lists the milestone's phases with the right counts, and v1 phases no longer count as unstarted.
3. **Dry run.** `gsd-tools query milestone.complete v2.0 --dry-run` completes and its move list is recorded. It is never run with `--confirm` and never with `--force`.
4. **Cleanup inventory and removals.** Worktrees (the repository has only its own), tmux servers, isolated Omp profiles, scratch directories and diagnostic scripts on the realm account, scratch build contexts, temporary images. Remove what this milestone created and is safe to remove. Keep and list for the owner: the rollback image and the Rust builder cache image (rollback and build-cache choices) and the private evidence directory (its size is recorded).
5. **Closing report.** The list of owner decisions with a recommendation for each, the single command the owner runs to confirm, and what stays blocked.

## Acceptance
- ROADMAP.md is reorganised with no loss (task 1 check), and the analysis and the dry run complete (tasks 2 and 3).
- Scratch items created by the milestone are gone, the kept items are named, and the evidence size is recorded.
- `milestone complete` was not run with `--confirm`.
