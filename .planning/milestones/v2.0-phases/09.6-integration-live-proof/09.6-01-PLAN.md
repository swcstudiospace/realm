## Constraints

- Live gates are env-gated in the same way as the existing `REALM_LIVE_*` gates. They are skipped in CI and run on the host under the realm account only.
- The live suite never runs on the root account's Podman service and never touches the main gateway.
- Live evidence (outputs, digests, timings) is written to the phase VERIFICATION file. It contains no host paths and no secret values.
- Cutover is clean: no compatibility shim and no fallback to the built-in driver. If `realm up` cannot use the production stack, it fails closed.

## Tasks and waves

### Wave 1 (sequential: the live run depends on the unit suite)

- T1, unit gate. Run the full unit suite with `npm test`. Confirm every module added in 9.1 to 9.5 has a test file, and that no test in those files needs a host dependency. Check: `npm test` passes; a list of new test files is recorded in the SUMMARY.
- T2, live suite (TST-02). Add `test/integration/production-driver.test.ts`, env-gated (the gate variable is set by the operator, not by the test). It checks, against the host:
  - the 14 checks pass for a container created by realm (driver's own create path);
  - the helper probe in the container: `/tmp` write denied with EACCES, `/workspace` write succeeds, `keyctl` returns EPERM, `NoNewPrivs` 1, `Seccomp` 2; and the control without the helper writes `/tmp`;
  - the supervisor RPC order (spike G3) against the live gateway, and no workload before `StartAgent`;
  - a 16 MiB stdin round trip through the sandbox (D-015 condition 1);
  - a non-zero exit from the workload is reported as that status (D-015 condition 2);
  - the helper's non-root start under the Landlock and seccomp profile (D-015 condition 3);
  - an allowlisted host:port connects and a non-allowlisted host fails; IPv6 is off in the container (RT-05);
  - sandbox delete leaves zero containers (G5).
- T3, live `realm up` (TST-03). With the production stack running, `realm up`, then `realm status` (must report active), then `realm down` (must leave zero realm-labelled containers, RT-09 evidence). Then set a wrong image digest in a copy of the configuration and run `realm up`: it must fail closed and leave no container. Record outputs in VERIFICATION.
