# Phase 9 Production Build: Risks

Each risk names the mitigation and the claim the mitigation tests. A claim is tested by a phase's acceptance criteria; a risk is closed only when that test passes and its evidence is recorded in the phase VERIFICATION file.

## Top five

1. **PR-01, the protocol contract is EXPERIMENTAL.** The IsolationBackend and SandboxProtocol headers say the API may change incompatibly before stabilization.
2. **PR-02, the production gateway path is untested.** The spike used TLS disabled, loopback, and one workload.
3. **PR-03, RT-03's supervisor placement is unknown.** The spike did not establish where the supervisor runs.
4. **PR-04, egress (RT-05) was never exercised.** The spike ran with `network: none` and no mediation.
5. **PR-05, host prerequisites are fragile.** One unexplained `failed to reexec` error, crun incompatibility, cgroup delegation, and reboot behaviour is untested.
