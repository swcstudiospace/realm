## Defects found live and fixed
1. The create body sent RLIMIT_NOFILE and RLIMIT_CORE; Podman's REST API prepends RLIMIT_ itself, so runc refused every start and the driver failed closed (7 of 9 scenarios failed on the first run on the new stack). Mock-based tests had encoded the wrong names.
2. The compute driver ignored SIGTERM while the gateway's watch stream was open: every restart waited 90 s and ended in SIGKILL. A 3 s grace then a forced cancel fixed it (measured restart 3.3 to 3.4 s).
3. The doctor's digest shared the 5 s probe bound; a cold read of a 106 MB binary outlasted it once. The digest has its own 30 s bound.
4. The image verifier reported every podman cp failure as a missing file; found when run across accounts; now only an absent file is a finding and any other copy failure exits 2.
