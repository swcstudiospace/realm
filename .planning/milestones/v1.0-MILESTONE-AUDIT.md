## 6. QUAL-01 catch sweep (silent sites)

Method. `grep` for `catch` across `src/` gives about 125 occurrences in 31 files, including comment mentions. Every catch body that was not a plain rethrow was read. Promise handlers were listed with `.catch(`, `.then(undefined`, `then(` with a rejection callback, and `.finally(`. A PCRE scan for empty and comment-only catch bodies found none. Classification: rethrows, returns a typed result, records the cause, or silent. Silent means the error is dropped or replaced with no code or cause, or the body is empty or comment-only.

Silent sites (10). Each is deliberate unless marked otherwise, and none records a code or cause.

1. `src/anda/client.ts:457`: `catch { failed = true; }` around a listener call. The listener error is dropped. The event is kept undelivered for redelivery (F2, F3). Deliberate.
2. `src/anda/client.ts:451`: `result.then(undefined, () => {...})` drops a listener rejection. It sets the event undelivered. Same rule as site 1. Deliberate.
3. `src/anda/client.ts:488-489`: `stamp()` catch returns null when the injected clock throws. The clock error is dropped. The transition stays unstamped until the clock works (site 448 rule). Deliberate.
4. `src/mcp/server.ts:176`: `catch` in `callTool`. A non-RealmError from the dispatcher becomes `{ code: -32603, message: "Internal error" }`. The error is not recorded, with no catalogue code, cause, or diagnostic. Not documented. This is the clearest silent site.
5. `src/lifecycle/controller.ts:330`: `return this.enterError(error)`. When a stop or destroy already owns the session, the probe error is not recorded (F4). When the session is still in service, the error is recorded with its code. Conditionally silent, documented.
6. `src/lifecycle/controller.ts:710-716`: `stopStarted`. When `exec.stop` fails and the fallback `exec.destroy` succeeds, the stop error is dropped with no code. Deliberate recovery; the stop failure leaves no trace.
7. `src/omp/plugin.ts:253`: superseded attach. The late rejection of `pending` is dropped (`() => undefined`). Its client is closed on success. Deliberate.
8. `src/omp/plugin.ts:258`: attach that the budget already failed. The late rejection of `pending` is dropped. The budget code was recorded when the race rejected (`plugin.ts:246-259`). Deliberate.
9. `src/daemon/channel.ts:105-122` (`replyForMalformedLine` returns null when no id is recoverable, comment at `:105-107`) with `src/daemon/daemon.ts:376-378` and `:397-399` (null leads to `dropSocket`, `daemon.ts:244-250`): a malformed line with no recoverable id gets no reply and no diagnostic. Silent by design. The rule is in code and in `.planning/phases/06-cli-daemon-and-host-packaging/06-01-SUMMARY.md:104`. It is not in `docs/integration/runtime-decision.md`. The client-side mapping of a closed socket was not read in this pass.
10. `src/audit/redact.ts:46-49`: `redactValue` catch returns the REDACTED sentinel. The error text is withheld because it may carry a secret (fail-closed). Deliberate.
