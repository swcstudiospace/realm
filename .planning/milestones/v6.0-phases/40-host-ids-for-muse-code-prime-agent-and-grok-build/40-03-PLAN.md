## Trust Boundaries

| Boundary | Description |
| --- | --- |
| Live test to the operator's real host files | The tests run real host CLIs; the operator's real files must not change |
| Live test to host processes and scratch directories | A host CLI may start background processes or write caches |
| Evidence to the repository | Dated results enter the registry and the pages |
| Documents to operators | Migration commands operators will run |

## STRIDE Threat Register

| ID | Category | Component | Severity | Disposition | Mitigation |
| --- | --- | --- | --- | --- | --- |
| T-40-13 | Tampering | A live run edits the operator's real Muse, Prime Agent or Grok configuration | high | mitigate | Isolated HOME and the host's own variable under a temporary root; the real files are hashed before and after and the test fails on a change; the executor also compares them by hand and records the result |
