<threat_model>
## Trust Boundaries

| Boundary | Risk |
| --- | --- |
| CLI and doctor output to the terminal and logs | Key, token or path disclosure |
| Keyring file to the CLI | A symlink or loose mode makes rotate write somewhere else |
| Docs to the reader | The docs promise more than the build gives |
| Recipes to the hosts | A later change puts a secret in a host-owned file |

## STRIDE Threat Register

| ID | Category | Threat | Severity | Disposition | Mitigation |
| --- | --- | --- | --- | --- | --- |
| T-32-22 | Information disclosure | status, rotate or the doctor prints a key, token or path | high | mitigate | Output is built from kids, ages, counts and mode names only; tests scan every output for the key text, the token shape and slash-bearing values |
| T-32-23 | Tampering | rotate follows a symlink or writes through a loose directory | high | mitigate | The CLI uses the plan 32-01 keyring module, which lstat-guards, checks owner and mode and writes atomically; the guard rows are repeated at the CLI and doctor |
| T-32-24 | Denial of service | revoke-previous strands every connected host | medium | accept | It is the emergency path and documented as such; planned rotation keeps old keys verifying through the grace period; hosts re-attach when they reconnect |
| T-32-25 | Repudiation | The doctor reports healthy while the keyring is unusable | medium | mitigate | In enforce every keyring failure class is a fail; the sandbox-overlap case is a fail |
| T-32-26 | Spoofing | The docs let a reader believe the token authenticates the host or stops a same-user process | high | mitigate | The first paragraph of Q10 states the limit; D32-1 lists it as an accepted residual; a doc test pins the statement |
| T-32-27 | Information disclosure | A later change delivers a secret through a recipe or manifest | high | mitigate | The recipe guard pins the 18 manifests and 15 recipes as bare and fails on an env, token or key member |
| T-32-28 | Elevation of privilege | A same-uid process runs the CLI verbs | low | accept | It can already read the key file; stated limit |

Accepted residuals: any process of the same user can run `realm host token rotate`, read the key file and attach as any host; the docs say so.
