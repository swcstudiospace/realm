## Trust Boundaries

| Boundary | Risk |
| --- | --- |
| Host process (and the model behind it) to the daemon socket | Calls without, with a stolen or with a wrong token; a model that cannot read the token channel still drives the host |

| Daemon to the audit chain | Forged or unbounded attribution lines |
| Token to logs, metrics, errors, doctor | Disclosure through a sink |
| Gate to dispatcher | A path that reaches the dispatcher without the check |
