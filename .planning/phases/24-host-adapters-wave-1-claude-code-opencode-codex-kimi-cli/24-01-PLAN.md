A line starting with `[` must match the header grammar `^\[\[?\s*K(\s*\.\s*K)*\s*\]\]?\s*(#.*)?$` where `K` is a bare key (`[A-Za-z0-9_-]+`), a basic-quoted key (`"[^"\\]*"`) or a literal-quoted key (`'[^']*'`); a line starting with `[` that does not match is `unreadable`. A non-header line matching `^\s*K(\s*\.\s*K)*\s*=` is a key assignment with its dotted segments; its full path is `context ++ segments`; it is `taken` when the full path is a prefix of the target or the target is a prefix of it; and, with no context (before any header), it is also `taken` when its first segment equals `path[0]`. A line that is neither (a continuation of a multi-line value) is ignored. The first `taken` or `unreadable` wins in file order; `free` otherwise.
