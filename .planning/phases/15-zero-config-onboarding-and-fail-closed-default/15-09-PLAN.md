<threat_model>

- Documentation is an instruction surface: the cutover text tells an operator to edit a systemd unit that runs a privileged account's driver. Each step must state the reversal path (save the unit first, daemon-reload, restart) and must not recommend a root variable or a secret value.
- The docs must not contain host-local absolute paths (`scripts/check/host-paths.mjs` enforces this under `check:docs`). Use placeholders such as `<state dir>` and `<config home>`.
- The doctor descriptions must match what the code prints, so an operator reading a failure is not sent to a wrong fix. Each fix text in the docs is quoted from `src/doctor/runtime-checks.ts` or is a paraphrase of it.

</threat_model>
