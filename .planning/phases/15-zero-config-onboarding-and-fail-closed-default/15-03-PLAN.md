# Plan 15-03: PR A docs, fail-closed default and the Upgrading notes (DEF-01, DEF-02)

## Objective

Make every owned document say the same thing about the policy mode: the default is `fail-closed` (D4), advisory is an explicit opt-in that is not containment, and existing users are told how the change reaches them (D-1502). Plan 15-01 made the code and its doctor say so; plan 15-02 guards the wording. This plan runs after both.

Most of the wording already reads correctly at HEAD (PR A is at commit 84f335b, subject `security!: default the policy mode to fail-closed (phase 15, part 1) (#19)`). This plan verifies each owned statement by reading it, edits only what is stale or incomplete, and adds the doctor sentence that D-1502 requires to both Upgrading paragraphs. P15-O3 is the reason the Upgrading text says the doctor exits 0.

Decisions owned: D4 (docs side), D-1502 (Upgrading paragraphs and the doctor mention), and the docs half of DEF-02. D-1503 is enforced by plan 15-02. D3 is Phase 16: no owned document presents fail-closed as containment of Omp's built-in write, edit or bash. CHANGELOG.md is release-owned under AGENTS.md and is not edited; the breaking marker is carried by the commit subject (D-1502). `docs/hosts/snippets/omp.md` is owned by plan 15-16 and already states the correct mode, so it is not edited here.
