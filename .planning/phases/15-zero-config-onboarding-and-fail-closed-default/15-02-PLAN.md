# Plan 15-02: docs guard against the old default claim (DEF-02, D-1503)

## Objective

Add the regression guard that keeps a published document from calling advisory the default (decision D4; locked decision D-1503). The guard is `scripts/check/default-mode.mjs`, wired into `npm run check:docs`. At HEAD it already exists, is wired, and has 18 tests; this plan verifies it against D-1503 and closes two gaps: nothing asserts the `check:docs` wiring from the test suite, and nothing runs the guard against the repository's own documents from the test suite. The guard is a regression guard for wording only. It is not containment, and nothing here is one.

Decisions owned: D-1503, and the guard half of DEF-02. The pull request subject and the docs text belong to plans 15-01 and 15-03. Decisions D4 and D-1501 are referenced as the reason the guard exists. P15-O3, D-1504 to D-1508, P15-O1, P15-O2 and P15-O4 are not in this plan.

## Verified state at HEAD (read in this planning pass)

- `scripts/check/default-mode.mjs:14` `SCANNED_FILES` = README.md, AGENTS.md, CONTRIBUTING.md, SECURITY.md, site/content/index.md. `:15` `SCANNED_DIRECTORIES` = docs. `:16` `EXCLUDED_DIRECTORIES` = docs/specs. These match D-1503. CHANGELOG.md, .planning/ and docs/specs/ are not in any scanned list.

- `scripts/check/default-mode.mjs:224-248` `collectFiles` reads only the listed files and .md files under docs/ and skips the excluded directory. `:260-276` `runCheck` takes `--root <dir>` only, returns code 0 with a one-line summary, or code 1 with one line per finding, and reads the real tree when no root is given (`DEFAULT_ROOT`, `:12`).
- `package.json` `scripts."check:docs"` = `node scripts/check/host-paths.mjs && node scripts/check/agents-sync.mjs && node scripts/check/default-mode.mjs`. `scripts."test:scripts"` = `node --test "scripts/**/*.test.mjs"`, so the guard's test file runs there too.
- `scripts/check/default-mode.test.mjs` has 18 `test(` cases at lines 55, 61, 74, 100, 108, 136, 143, 148, 152, 163, 195, 204, 220, 238, 251, 266, 271 and 277. Both polarities are covered: flagged phrases at :74 and :204, true statements at :108, :220 and :251, qualified and clause-bound cases at :136 and :238, and the listed locations at :163 and :195.
- Tracked Markdown outside docs/specs, CHANGELOG.md, .planning/ and the root files: the only files that mention advisory are AGENTS.md, README.md, docs/hosts/snippets/omp.md, docs/integration/hardening-plan.md, docs/integration/omp-lifecycle-runbook.md, docs/integration/omp.md, docs/integration/runtime-decision.md, docs/policy-reference.md and site/content/index.md. CLAUDE.md, CONTRIBUTING.md and SECURITY.md do not mention advisory. Reading each mention (plan 15-03 Task 3) found no sentence that asserts advisory is the default. The guard is the executable form of that reading.
- `.planning/PROJECT.md:48` and `:74` still say "advisory default, fail-closed opt-in". D-1503 excludes `.planning/`, and this plan does not edit it.

## Gaps found and closed by this plan

1. No test asserts that `check:docs` runs the guard. If someone removes the step from package.json, the guard's own tests still pass. Add a test that reads package.json and asserts that `scripts["check:docs"]` contains `node scripts/check/default-mode.mjs`.
2. No test runs the guard over the repository's own documents. A future document that asserts advisory is the default would fail `check:docs` only, not `npm run test:scripts`. Add a test that runs `runCheck([])` against the real tree and asserts code 0.

Verified with no edit: the scan lists, the exclusions, the patterns, the runner's output, and the 18 existing tests.

<threat_model>
- T-15-02-1 (Tampering, documentation): a document reintroduces "advisory is the default", so users believe a fail-open mode is the default. Disposition: mitigate. The guard fails `npm run check:docs` and the repository-tree test fails `npm run test:scripts`.
- T-15-02-2 (Repudiation, guard drift): the guard stops being run. Disposition: mitigate. The wiring test fails if the `check:docs` step is removed.
- T-15-02-3 (Denial of service, false positive): the guard flags a true sentence and blocks a docs change. Disposition: accept with mitigation. The existing truth-case tests and the exemption words cover true statements; a new false positive is fixed by a new truth-case test, not by weakening a pattern.
- T-15-02-4 (Information disclosure): none. The guard reads only tracked Markdown and prints file names, line numbers and matched phrases.
- The guard is wording enforcement, not a security control. Nothing in this plan presents it as containment of Omp's built-in write, edit or bash (D3 is Phase 16).
</threat_model>
