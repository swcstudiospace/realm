## Requirement mapping

| Requirement | Tasks | Evidence required |
|---|---|---|
| OMPX-05 | T1, T2 (offline), T3 (human) | A doubly gated actual Omp to daemon to driver to OpenShell to rootless Podman write has identical host-root and sandbox `/workspace` bytes, the expected container identity, and a paired admission and result in the audit log, matched by session and op id |

### T2. Production driver test: the scenario is defined and skips without the opt-ins

- Verify: `npm run build && env -u REALM_LIVE_OMP -u REALM_LIVE_PRODUCTION node --test dist/test/integration/production-driver.test.js`. The expected result is exit 0 with the new scenario skipped.

### T3. HUMAN-NEEDED: live production acceptance (NOT EXECUTED)
- Files: none beyond T1 and T2. Writes evidence under the owner's live window only.
- Checkpoint: stop and ask the owner for a live window. Give the exact steps, the expected result and the form of the reply.
