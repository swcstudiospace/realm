## Defects found by the live proof and fixed
1. The create body sent rlimit types as RLIMIT_NOFILE and RLIMIT_CORE. Podman's REST API takes them without the prefix and adds it itself, so runc refused the start (wrong rlimit value: RLIMIT_RLIMIT_NOFILE) and the driver failed closed. A first run on the new stack failed 7 of 9 scenarios (the two that expect a failure passed). The cause was found from the Podman API service journal and a live probe of the create body; fixed in the body, and the test pins now name the REST forms. The verifier keeps the OCI names the inspect reports.
2. The compute driver never exited on SIGTERM while the gateway held its watch stream: `systemctl restart` waited the 90 s stop timeout and systemd killed it, at every restart. The shutdown now has a 3 s grace, then cancels open calls. A normal restart measured 3.4 s.
3. `realm doctor`'s binary digest shared the 5 s probe bound; a cold read of the 106 MB gateway binary on a busy host outlasted it once and made the item warn. The digest now has its own 30 s bound.
