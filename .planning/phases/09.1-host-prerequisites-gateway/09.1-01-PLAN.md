## Constraints

- The main gateway unit and configuration, and the root account's rootful Podman service, are not changed. T1 records their digests before any change, and the phase ends with them equal to those digests.
- Rootless only. No privileged container. No socket mounted into a container.
- Gateway TLS and JWT material is written only under the realm account's state directory (directory 0700, key files 0600). Nothing under the root account's configuration directory.
- No host path, key, or secret value goes into the repository or `.planning`. The phase writes the baseline digests to the realm account's state directory.
- The gateway TOML is rendered by code (`src/runtime/gateway-config.ts`), so the production profile is tested, not hand-edited.

## Tasks and waves

### Wave 1 (sequential: host state changes depend on each other)

- T1, baseline (read only). Record SHA-256 digests of the main gateway configuration file, the main gateway unit file, and the root Podman service's configuration. Record linger state and the user-manager state of the realm account. Write them to the realm account's state directory. Check: the baseline file exists and lists seven digests and two states. Rollback: none (read only).
- T2, HC-02 runtime for the realm account. Write the container configuration with the OCI runtime set to `runc`, in the account's own configuration directory. Check: `podman --remote info` run as the realm account reports runtime `runc`. Rollback: delete the file (HC-02).
- T3, HC-01 linger. Enable linger for the realm account. Check: linger state reads enabled; the account's user manager is active. Rollback: `loginctl disable-linger` (HC-01).
- T4, HC-03 user-manager unit for the rootless API. Add a unit with `Delegate=yes` and `DelegateSubgroup`, enable it, and point the realm driver's `--podman-host` at its socket (the socket path is set in config, not in code). Check: the unit is active; `podman --remote info` reports `rootless` true and a 5.x version; a container created with a memory limit and a pids limit starts. Rollback: HC-03 revert (disable, delete unit, `daemon-reload`).

### Wave 2 (sequential: measurements on the state from wave 1)

- T5, soak (PR-05). Run `podman --remote info` 20 times, and run 10 cycles of create, start, inspect, and remove on the pinned base image (digest in configuration, see the note in phase 9.3). Check: all calls exit 0; no realm-labelled container remains after the cycles. Record timings and the first error if any. Rollback: remove any test container.
- T6, reboot test (owner window). The owner schedules one host reboot. After it: linger is still enabled, the rootless API answers without a manual step, and T5's first check passes. Check: recorded in the SUMMARY with the boot time. This task stays PENDING until the owner's window; the phase does not close without it (PR-05). Rollback: HC-01 and HC-03 revert.

### Wave 3 (parallel: disjoint files)

- T7, gateway configuration renderer. Add `src/runtime/gateway-config.ts` (pure function) that renders the realm gateway TOML from inputs: bind address, compute driver name, TLS certificate, key, and client-CA paths, JWT signing key, public key, and kid paths, and the driver socket path. It must write `[openshell.gateway.tls]` and `[openshell.gateway.gateway_jwt]`, must never write `disable_tls`, and must throw on any relative path or missing input. Add `test/runtime/gateway-config.test.ts`. Check: unit tests pass; the rendered output contains no `disable_tls`; a relative path throws.
- T8, TLS and JWT material (HC-06). Run the gateway's `generate-certs` subcommand with an explicit output directory under the realm account's state directory. Confirm the exact flags against the installed binary before running; the spike used this subcommand. Check: directory 0700; key files 0600; no file was written under the root account's default configuration directory by this step. Rollback: delete the generated directory (HC-06).
- T9, docs. Add a "Production gateway profile" section to `docs/integration/openshell.md` with repo-relative references only. Check: `npm run check:docs` finds no host path in the file (run once at phase end).

### Wave 4 (gates, after the phase's changes)

- Run `npm run typecheck`, `npm test`, `npm run lint`, `npm run check:docs`. Confirm the main gateway digests equal T1's baseline.
