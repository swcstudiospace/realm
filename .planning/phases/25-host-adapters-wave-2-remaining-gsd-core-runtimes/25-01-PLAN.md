| Boundary | Risk |
| --- | --- |
| Registered entry → host process | A wrong or drifted entry makes the host launch something other than `realm mcp --host <id>`, or nothing |
| Existing user config → installer | Hostile, large, commented or unusual content (including a settings file that holds API keys) reaches the rewrite |
| Table row → user's machine | A wrong home, file or variable reports success and changes nothing the host reads (wrong-product install) |
| Host's own rewriter → Realm's entry | Copilot, Qwen, Kilo normalize or migrate the file after Realm wrote it |
| Workspace → host project config | A workload-written project file shadows the user-level `realm` entry (R-25-01; accepted, documented in 25-04) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- | --- |
| T-25-01 | Tampering | Recipe value | high | mitigate | Values equal the host's own output (golden test) or the documented shape, and `defaultManifestFor(id).launch` (invariant test); the table is deep-frozen; a changed arg fails a named test. |
| T-25-02 | Tampering | Existing config content | high | mitigate | Engine refusals proven per host on the real row: non-object, wrong-typed parent, BOM, invalid UTF-8, oversize, lossy number, `__proto__`/`constructor`/`prototype` keys, differing entry, JSONC (augment, kilo, qwen, pi); nothing is written on refusal (tree hash, no receipt, no audit directory). |
| T-25-03 | Tampering | Symlinked or special file or directory | high | mitigate | Symlinked file, symlinked config directory, directory and FIFO at the file name refused without a hang; no write follows a symlink (`O_NOFOLLOW`, engine); a created `data/settings` (cline) is removed only when Realm created it. |
| T-25-04 | Information disclosure | Logs, receipt, audit; shared settings files with secrets | medium | mitigate | A unique marker planted in each seed (the suite's `MARKER`) never appears in `host.log`, the receipt or any audit line; CLI output never contains the root path; mode of an existing file is kept. |
| T-25-05 | Spoofing | Wrong-product or wrong-file install | medium | mitigate | Real table rows (not fixture entries) are exercised; the host's own variable is pinned and the GSD-only names are asserted absent; kilo writes `kilo.json` and never the `.jsonc`; antigravity detects `.gemini/config`, not `.gemini`; cline creates nothing when `~/.cline` is absent; the validator tier (25-03) proves each host parses what was written where it can run. |
| T-25-06 | Tampering | Host normalization read as drift | medium | mitigate | Copilot's normalized form and Kilo's `$schema` rewrite are tested to stay `ok`; a hand-written entry that lacks the canonical `tools` is `foreign-content`, never silently rewritten. |
| T-25-07 | Tampering | Concurrent writer on a shared file | medium | mitigate | `stageHook` test proves a change between plan and write is `concurrent-change`, the other writer's key survives and install resumes from the pending receipt. Residual R-25-02 (the window after the final hash check) is accepted and documented. |
| T-25-08 | Elevation of privilege | Registered launch | low | accept | Bare `realm` resolves on the host's `PATH`; a hostile `realm` earlier on a user's `PATH` is a same-user control and out of the model (D-25-07). |

Accepted residuals: R-25-01 and R-25-02; a commented real settings file (augment, kilo) is refused until the user removes the comments or uses the host's own add command (OQ-25-06).
