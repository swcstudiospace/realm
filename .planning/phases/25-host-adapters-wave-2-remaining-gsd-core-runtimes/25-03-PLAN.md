<threat_model>
## Trust Boundaries

| Boundary | Risk |
| --- | --- |
| Live test → the operator's real host configuration | A rehearsal registers Realm in, rewrites or leaves state in a real `~/.qwen`, `~/.copilot`, `~/.hermes`, ... |
| Live test → network and credentials | A host CLI starts, phones home, prompts a model or reads a credential from the real environment |
| Host CLI → process table | A spawned host or its helper outlives the test |
| Fetched scratch binaries | An executable named by `REALM_<ID>_BIN` is run |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- | --- |
| T-25-17 | Tampering | Real host configuration | high | mitigate | The environment is built from an allowlist under a temporary root (`isolatedHostEnv`); the helper throws before creating anything when `HOME`, an override variable or the stub directory is outside the temporary directory; the operator's real configuration files are hashed before and after each scenario; a run skips when a Realm receipt for the host already exists in the shared state directory. |
| T-25-18 | Information disclosure | Credentials in the environment | high | mitigate | No `*_API_KEY`, token or proxy variable is copied (hermetic test); only commands that never prompt a model are run (`mcp list`, `mcp get`, `config mcp`, `mcp test`); no login is performed or required for any of them (E-QW2, E-CP2, E-AU2, E-CB1, E-KL2, E-PI1, E-HM1). |
| T-25-19 | Denial of service | Slow or interactive hosts (`auggie` about 40 s, `codebuddy` 30 to 45 s, `agent mcp list` a menu) | medium | mitigate | Per-command bounds scaled by `REALM_TEST_TIMEOUT_SCALE`; stdin closed; every spawn under a process-group kill and a sweep when the command ends; a bound kill of the cursor menu is the expected outcome, written down. |
| T-25-20 | Elevation of privilege | `REALM_<ID>_BIN` | medium | accept | An operator-chosen executable is run with the isolated environment only; it must be absolute and an executable regular file (`resolveExecutable`); choosing a hostile binary is a same-user action outside the model. |
| T-25-21 | Spoofing | Overclaiming evidence | medium | mitigate | A skip names the first missing prerequisite; the record says "not run" where nothing ran; hosts without a validator (`antigravity`) or a floor (`pi`) have their gap written; nothing says "proven end to end" for a config-only host. |

Accepted residuals: R-25-01 (project-level shadowing) is not exercised by any rehearsal and is documented in 25-04; a host version newer than the recorded one runs and is recorded, never skipped.
