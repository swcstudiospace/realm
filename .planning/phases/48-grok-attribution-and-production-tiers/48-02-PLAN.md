## Trust Boundaries

| Boundary | Description |
| --- | --- |
| Test code to the operator's real host configuration | a production test runs a host that writes to its configuration home |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- | --- |
| T-48-06 | Tampering | A production test writing the operator's real Muse Code, Prime Agent or Grok configuration | high | mitigate | Isolated homes through each host's own relocation (HOME for Grok with the recorder restoring the account HOME for realm only); the real file is hashed before and after and must be equal; Grok never uses the real ~/.grok |
| T-48-07 | Information disclosure | A credential or a restored value printed or recorded | high | mitigate | No credential is supplied; the recorder logs names and never values; hermetic rows assert it |
| T-48-08 | Repudiation | A gap recorded as a pass, a handshake-only wire called a full wire | high | mitigate | Skip is not-run; the handshake-only mode has its own name, failure text and registry note wording; the registry note starts with the blocker id for a blocked host |
| T-48-09 | Denial of service | A leftover Grok leader, Prime Agent daemon or Muse process after a failed run | medium | mitigate | A per-run leader socket; the process-group kill covers the host's children; the window checks residue (plan 48-03) |
| T-48-10 | Elevation of privilege | A test that sets a gate variable and so runs a production tier in CI | medium | mitigate | A hermetic row asserts no module sets an opt-in or REALM_LIVE_PRODUCTION; CI never has the gate |
