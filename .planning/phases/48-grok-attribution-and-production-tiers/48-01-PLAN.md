## Trust Boundaries

| Boundary | Description |
| --- | --- |
| Third-party host CLI to the network | a host may contact its vendor (update checks, telemetry) from a throwaway home with no credential |
| Third-party host CLI to the account home | a host writes configuration, sessions and a Grok leader socket |
| Evidence to the repository | probe results are copied into the summary and the tests |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- | --- |
| T-48-01 | Information disclosure | A credential in the shell reaching a host or a log | high | mitigate | The probe environment is minimal and credential-free (count recorded, names and values never); no login; the stub logs method and tool names only |
| T-48-02 | Tampering | A probe changing the operator's real host configuration | high | mitigate | Every probe has its own HOME and relocation variable; the real files are hashed before and after and must be equal; a difference is recorded and undone by removing what the probe created |
| T-48-03 | Repudiation | An outcome chosen by preference or from a cell that was not run | high | mitigate | The rule of Task 2 names the deciding cells; a cell not run is not-available or not-found, never inferred |
| T-48-04 | Elevation of privilege | A shipped launcher that carries another host's label or none | medium | mitigate | The labelled-launcher guard test covers every added file; no bare launcher |
| T-48-05 | Denial of service | A leftover host process (a Grok leader) after the probes | low | mitigate | Per-run leader socket; the residue step lists and removes leftovers and records them |

Accepted residual: the hosts' own network use in a probe is not measured (it is not contained; GAP-48-02 in plan 48-04).
</threat_model>
