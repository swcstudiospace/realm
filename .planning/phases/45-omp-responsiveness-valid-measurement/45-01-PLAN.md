Run env with the clear flag and exactly XDG_RUNTIME_DIR (RUNTIME_DIR) and PATH (the system directories) set, then systemd-run with the options --user --scope --quiet --collect and the double dash and a shell command that prints /proc/self/cgroup, then the scope's own cgroup.controllers and the first two lines of its cpu.pressure (the scope directory is the mount root plus the path field of /proc/self/cgroup), and starts a detached child (setsid, a sleep of 20 seconds in the background) and prints that child's /proc/PID/cgroup so it can be compared with the scope's. After the command and the sleep end, systemctl --user list-units with the scope type shows no leftover scope of the probe (record the output either way). Record the exit status and the stderr text of every step.
    P4, cpuset and allowed CPUs. The same wrapper as P3 with the property AllowedCPUs set to 0-1, running taskset with the print flag on its own pid; record whether systemd-run refused, ignored the property or applied it, with the literal text. Also cat cpuset.cpus.effective of the scope if present, and whether a cpuset.cpus file exists in the scope at all.
    P5, per-cgroup pressure moves. Two scopes, each with the P3 wrapper, in sequence, each reading the scope's cpu.pressure some line total field (the fifth awk field of the some line, after the equals sign) at its start and after 15 seconds, together with the system file's some total at the same two moments (cat /proc/pressure/cpu): scope A runs one CPU burner (a shell busy loop under the timeout command, 15 seconds); scope B runs sleep 15. Record the four deltas in microseconds, the elapsed seconds and the one-minute load at both moments. The point is whether the scope's total moves with the host's contention and stays near zero for a sleeper.
    P6, per-thread run-queue delay. Under the P3 wrapper and once outside any scope, run node with a one-line program that reads /proc/self/task/PID/schedstat (PID is its own process id, read from process.pid) before and after a busy loop of two billion iterations, and prints both lines. Record the three fields before and after, which field moved, and whether the file is readable by the same account. Also record that the file of a thread of another account is or is not readable (read the file of PID 1; record the result, an error is expected and is a result).
    P7, taskset. taskset with the print flag on the login shell's pid; taskset with a core list of 0 running a child that prints its own affinity.
    P8, the two descriptions of load. Six samples ten seconds apart, each printing the first line of /proc/loadavg together with the some and full lines of /proc/pressure/cpu and the some line of the account's slice cpu.pressure; also nproc.
    P9, kernel facts. uname with the release flag; whether /proc/config.gz exists, else the boot config file of that release, searched for CONFIG_PSI, CONFIG_PSI_DEFAULT_DISABLED, CONFIG_SCHED_INFO, CONFIG_SCHEDSTATS; cat /proc/sys/kernel/sched_schedstats; systemd-run with the version flag; node --version; the full path and version of omp (omp --version; if omp cannot run as this account the probe stops and reports BLOCKED, because the later windows need it); the full path of the node the account's PATH finds.

    P11, the root-assisted options (read only; nothing is changed). cat cgroup.subtree_control of the mount root; systemctl show with the property AllowedCPUs for the units system.slice and user.slice; the same for the account's user manager.
