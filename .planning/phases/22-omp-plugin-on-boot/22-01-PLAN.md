## Trust Boundaries

| Boundary | Risk |
| --- | --- |
| Omp host events and tool names → plugin guard | A hostile or malformed tool name, or an event with no working directory, reaches the guard |
| Plugin → daemon control channel | A late or foreign attach result adopted after shutdown or after a newer attach |
| Plugin options → bounds | A bound taken from a manifest could disable a budget or inflate a retry cap |
| Sandbox workload → host plugin | The workload cannot call the plugin; it can only shape tool calls and status the model sees |
